
# Personal Expense Tracker

## Project Description
A Python-based Personal Expense Tracker that allows users to record, view, filter and analyse their daily expenses.

## Features
- Add new expenses
- View all expenses
- Filter expenses by category
- Filter expenses by month
- Calculate total spending per category
- Display grand total and biggest expense
- Store expenses permanently using CSV files

## Technologies Used
- Python
- CSV Module
- Datetime Module
- Collections Module

## How to Run

1. Install Python 3.10 or newer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute:

python expense_tracker.py

## Project Files
- expense_tracker.py - Main Python program
- expenses.csv - Stores expense records
